# 🏠 **Furniture Sales Interactive Dashboard - Excel**  

## 📌 **Overview**  
This repository showcases an **interactive furniture sales dashboard** built in **Excel** using:  
✔ **Pivot Tables**  
✔ **Power Pivot**  
✔ **Power Query**  
✔ **Icons & Charts**  
✔ **Slicers & Dynamic Filters**  

This dashboard provides valuable insights into **sales performance, product trends, and regional distribution**, making data-driven decisions easier.  

## 📊 **Dashboard Features**  
✅ **Dynamic Filters** – Month, Payment Type, Order Status  
✅ **Key Metrics** – Sales Amount, Total Orders, Profits  
✅ **Product Performance** – Top-selling products & categories  
✅ **Regional Sales Breakdown** – Sales distribution across different zones  
✅ **Order Status Analysis** – Delivered, Canceled, Buyer Returns  

## 🖥️ **Technologies Used**  
- **Microsoft Excel**  
- **Pivot Tables, Power Pivot & Power Query**  
- **Data Visualization (Charts & Graphs)**  


## 🚀 **How to Use**  
1. **Download the Excel file** 📥  
2. Open it in **Microsoft Excel (2016 or later)**  
3. Use the **filters & slicers** to explore insights dynamically
